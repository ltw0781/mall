# 개인 카페 홈페이지

## 프로젝트 목적
- 카페의 신규 고객에 대한 홍보
- 매장 방문 전 필수 정보 전달
- 모바일 앱 주문/결재 기능을 보조하는 정보 허브 역할
- 네이버/카카오 지도, SNS 광고 유입 고객의 랜딩 페이지


## 프로젝트 범위
- 포함 범위
    - 반응형 웹사이트 디자인 및 개발
    - 관리자 페이지(CMS) 구축
    - 지도 API 연동
    - 앱 다운로드 유도 페이지
    - 회원가입 / 로그인

- 제외 범위
    - 홈페이지 주문/결재 기능
    - 배달 서비스

- 별도 프로젝트로 추후에 개발
    - 포인트 스템프 쿠폰( 추후 개발 )
    - 앱 개발 (별도 프로젝트)

## 사이트 구조
- 메인 페이지
    - 브랜드 소개 페이지
    - 메뉴 안내( 메뉴 목록 페이지 )
    - 매장 안내 페이지( 매장 사진 )
    - 공지 / 이벤트 페이지
    - 오시는 길 ( 지도API 연동 )
    - 앱 다운로드( 추가기능 )
